## 卡池与出货规则

当前目录收录从「熔火灼痕」到「锻砧、行囊与蜜糖／小刻」的 14 个常规限定池。复刻、庆典及常驻池可作为辅助记录保存。常规限定评分使用 [账本目录](../tools/gacha_rating_app/character_ledger.js) 中定义的可出角色和池序。

- 主池六星基础概率为 0.8%，从连续未出后的第 66 抽起每抽增加 5 个百分点，第 80 抽必出六星。六星出货重置水位，水位可跨常规限定池继承。
- 单池第 120 主抽前未出过主池当期 UP 时，第 120 抽强制出当期 UP。提前抽到主池 UP 会解除这次保障。80 抽六星保障仍按普通规则生效。
- 独立加急每次十抽。每抽六星概率为 0.8%，当期 UP 为 0.4%，限定为 `0.008 × 9/14`。加急不改变主池水位或首 UP 保障。免费主抽仍计入主池进度。
- 每 240 主抽的信物单列。在 B 区，确认的信物计入 UP 份数，也参与追潜停手目标。信物不计入实际抽出的六星或限定数量。

## A、B、C 怎么计分

| 分段 | 实际账本 | 参照怎么停 |
| --- | --- | --- |
| A 大保底区 | 从每池开头到首个主池 UP 当抽，包含这次出货。未出首 UP 时使用实际观察窗口。 | 完成池按出首个主池 UP 当抽即停的平铺参照。出现完成池时，把其他未完成 A 段的投入和产出一并纳入比较。全未完成时按各池观察窗口计算。 |
| B 无大保底区 | 从首 UP 之后开始，水位从零起算。六星和限定结算到末次主池六星，UP 的结算范围还考虑已确认的信物。 | 有追加份数时，参照追到与实际相同的追加自然 UP 和信物总份数。没有追加份数时使用实际观察窗口，未再出 UP 单独计分。 |
| C 加急 | 汇总已用加急的抽数和对应出货。 | 按相同加急抽数的独立二项分布比较产量。 |

动态规划按水位、出货量和停点累积参照概率。A 有已完成池时，对相同总产出比较永久抽成本。B 在同一类停手条件下，对实得产出比较永久抽成本。成本越低得分越高，成本并列时计一半概率。全未完成 A 的六星和限定比较观察窗口内的产量，未出 UP 的分支按仍未出货的概率计分。

沿用实际账本可确认的免费位置和免费额度。首 UP 后的尾抽在实际发生继承时连同对应永久抽归入下一池 A，每笔只归一次。尚未继承的尾抽单列为待结算。

```text
轴基础分 = Σ(分段分数 × 该分段参照期望产量) / Σ(该分段参照期望产量)
```

这是一项分段加权分。整轴的分布会随固定预算、平铺或追潜等停手方式变化。可按同一策略比较 A/B/C、合并分和两端占比，查看权重如何影响结果。 [角色仿真对照](CHARACTER_SCORE_SIMULATION.md)

## 限定的歪 New 修正

限定基础分把每次限定出货计为一份。歪 New 单独计算，固定已记录的出货位置与当期 UP 身份，对其余六星按常驻合计 `5/7`、两个可歪限定各 `1/7` 递推。每条参照路径按时间顺序更新自己的持有图鉴，同一角色重复获得最多算一次 New。首获当期 UP 会更新图鉴，歪 New 数只统计首次歪出的限定。

令 `S` 为限定基础分、`S_new` 为歪 New 数的中位分位分、`E` 为期望歪 New 数。

```text
w = 0.20 × E / (1 + E)
d = (S_new - 50) / 50
New 调整 = w × d × (100 - S)   当 d ≥ 0
New 调整 = w × d × S           当 d < 0
限定分 = S + New 调整
```

New 分以 50 为中性。可评估机会越多，调整的有效权重越大，上限趋近 20%。图鉴不明或没有可评估机会时显示基础分。雷达悬停可查看 A/B/C 基础分、无 New 加成总分和带符号的 New 调整。 [New 图鉴 DP](../tools/character_abc_score/flat_new.js)

## 角色五星

用同一范围的武库配额 `Q`、总抽数 `T`、实际抽出的六星数 `K6` 反推五星数 `F`。主抽 `N` 和已用加急次数 `R` 满足 `T = N + 10R`，总抽数仍包含免费主抽。配额不全或结果无法反推合法整数时，五星保留缺项。

```text
F = (Q - 20 × T - 1980 × K6) / 180
E = 0.13411295200285397 × N + 1.1980598575793349 × R
p = E / N
z = (F - E) / sqrt(N × p × (1 - p))
五星分 = 100 × Φ((z - μ) / σ)
μ = -0.08096081491239257
σ = 0.5754562752790213
```

`Φ` 为标准正态累积分布函数。`μ`、`σ` 由 11 期固定参照策略下的 2,000 条离线模拟校准。14 池目录沿用这些冻结参数，所以五星期望和分数属于近似参照。雷达标签显示 `F − E` 对应的「多／少」，悬停显示欧非分数和期望产量。 [五星实现](../tools/character_five_score/scorer.js) · [冻结参数](../tools/character_five_score/parameters.json)

## 缺失历史与兼容参照

账本验证会按轴保留来源冲突和机制冲突。A/B/C 参照所需的水位、赠券、信物或图鉴证据不完整时，生产入口可按可确认的账本区间使用兼容参照。含中断或缺池的限定轴可能采用旧图鉴口径，结果明细会标明方法与回退原因。兼容分应按对应参照解读。 [角色评分入口](../tools/gacha_rating_app/character_score.js) · [A/B/C 合分](../tools/character_abc_score/flat_score.js) · [兼容路由](../tools/gacha_rating_app/character_result_score.js)
